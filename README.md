# 🦄 Math-unicorn

Тренажёр таблицы умножения с милым единорожком.  
Зарабатывай очки — одевай своего единорожку: кепка, кофта, штаны, кроссовки!

## 🎮 Как играть
- Решай примеры на умножение
- За правильный ответ +5 очков
- За ошибку -2 очка
- На 100/200/300/400 очках — новая вещь на единорожке
- На 400 очках — финальный салют! 🎆

## 🚀 Запуск
Просто открой `index.html` в браузере или установи как PWA.

## 📱 Установка как приложение
Открой в мобильном браузере → «Добавить на главный экран».

## 📦 Стек
- Чистый HTML/CSS/JS
- Web Audio API для звуков
- Canvas для салюта
- PWA (manifest + service worker)
